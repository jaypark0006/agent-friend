# Mosaico 随身通知

用户于2026-10-07授权：本机Codex完成有实际交付的任务时，向自己的随身屏发送简短消息并生成合适配图。每次任务收尾一次；失败/阻塞必须如实标识，不能画成成功。不发送密钥、完整日志、客户资料或敏感正文。用户当次要求不通知时跳过。

## 执行

1. 根据实际结果写简短中文标题和1–3行摘要；编译/安装成功不等于测试通过。不要为了通知额外测试主任务。
2. 用随附脚本生成480×480状态卡并发送。脚本需要Python3及Pillow；优先使用已有带Pillow的Python（可通过workspace dependencies工具定位），缺依赖时说明，不擅自全局pip安装。

```sh
python3 SKILL_DIR/scripts/notify.py --title '任务已完成' --text '已更新控制界面。已编译刷入；未做功能测试。' --status done
```

将SKILL_DIR替换为本技能目录的绝对路径。status为done/error/attention。摘要≤1024 UTF-8字节。默认先文字再配图，最后请求显示图片页；这只切当前页面，不更改持久化“自动切换”设置。用户要求不打断当前页面时加`--keep-view`：仍遵循设备原有自动切换设置，不承诺强制保持。

默认卡片是代码绘制的高对比任务海报，包含标题、摘要、时间、状态图形。若任务适合插画，且有图像生成工具，生成与交付相关、无敏感信息的方形插画，然后传`--image /absolute/path.png`；脚本将它缩放完整放入卡片，不截取局部。没有图像生成工具时正常使用绘制卡片，不阻塞通知。

## 随身发现与发送边界

脚本固定目标硬件MAC `1c:29:04:d0:ad:2a`（来自官方设备状态；Wi-Fi接口尚未经本技能实测绑定）。旧IP仅作候选，不作为身份。先查本机ARP和成功地址缓存，再查当前默认接口的本地IPv4网段（最多256地址），读取/api/info且核对ARP MAC。禁止猜测另一个MAC或向首个同型号设备发送；没有匹配就报告设备未找到。设备屏幕的新IP可通过`--ip`给候选，但仍核对MAC。若实际Wi-Fi MAC不同，需根据官方身份/用户确认更新绑定，不自动学习任意响应者。

Mac和设备必须同一可直连局域网/热点。无mDNS依赖，不需要固定IP；访客隔离、VPN默认路由、大网段或跨公网可能无法发现，提示用户提供IP/接入同网，不自动端口转发或部署公网中继。HTTP无鉴权，MAC匹配只是局域网防误投，不是密码学认证。

不在当前“准备技能”任务中执行试推。以后正常调用技能属于用户授权通知，不是功能测试。发送请求各一次；超时可能已经接收，不能自动重发。输出保留每一步的accepted和错误，部分成功不能说完整成功。accepted只表示设备接收，不表示屏幕已显示或用户已读。设备离线时简短告知，不轮询、不排队旧通知、不影响主任务交付。
