## 一、改动

### 1. 缺字
- 常规体 20/24/32 在原 4118 字之外补上 GB2312 二级汉字 3008 个和日文假名（U+3040–U+30FF），共 7318 字（字库中实际有字形 7305 个）。粗体 24/32 不补，保持 4118 字。
- 粗体标签里只要有粗体没有、常规体有的字，整段改用同字号常规体显示，不在同一行里混用两种字重（`screen_ui_text_font`，`screen_ui_set_text` 换文字时重新判断）。逐字回退链为粗体 → 同字号常规体 → 占位点。
- 两套字体都没有的字，画成一个淡色小方点（字号的 1/4，最大 8px，透明度 0x50，用文字颜色），替代 LVGL 的方框；汉字等宽字符保留一个字宽，避免后文挤到一起。
- 组合符号、零宽字符、变体选择符（FE0F）、emoji 肤色修饰符和标签字符不占位也不画点，“⚠️”“👍🏻”只显示一个点。
- 字库包从 6.47 MB 增至 9.32 MB；度量表随之增大约 135 KB（XIP 下位于 PSRAM）。固件 11,921,609 字节，占 ota_0（0xCF0000）的 87.9%。
- 字形读取：576 字节的栈上缓冲改为静态缓冲；字形像素超过缓存槽（1152）时直接拒绝，不再截断读取。当前最大字形 1056 像素。
- `tools/gen_all_chars.py` 同时写出 `all_chars.txt`（粗体）和 `all_chars_extended.txt`（常规体）；`tools/gen_flash_font.js` 按字体选择字表。来源与覆盖范围记录在 `main/SCREEN_FONT_PROVENANCE.md`。

### 2. Agent、Session、任务名
- `/api/widget` 新增可选字段 `agent`（≤31 字节）和 `session`（≤47 字节），`title` 只放任务名；GET 返回中带回这两个字段。
- 不传 `agent` 的旧请求只按第一个冒号（半角或全角）取出 Agent，冒号后整段原样作为任务名，不再按“-”拆分。传了 `agent` 时，只有标题前缀与它相同才去掉前缀。
- 此刻页头像旁改为三行：Agent（粗体）、Session（灰色，单行，过长加“…”，没有时隐藏）、已运行时长（多 Agent 时带 `1/2`）。确认页同样三行：「Agent 在等你」、Session、任务名（多个确认时带序号）。
- 任务列表副标题为「Agent · 当前状态」；控制中心上的确认横幅只显示 Agent 名。
- 多 Agent 轮流显示按 `agent` 字段区分 Agent。

### 3. 可能中断的任务
- 进行中的任务超过 10 分钟没有任何上报即视为“可能中断”（`screen_agent_stale`）：
  - 此刻页不再把它当作工作中，也不计入「还有 N 个任务」；
  - 空闲页出现入口「N 个任务可能中断了 ›」（灰点），点按进入任务页；未读消息入口优先，其次是这个入口，再次是新画面；
  - 任务列表中排在进行中任务之后：灰色方块、灰色标题、副标题「Agent · N 分钟没有更新」（满 60 分钟显示小时），右侧显示最后的进度；列表每分钟刷新一次；
  - 副板灯提示随此刻页状态变化，不再呼吸；
  - GET `/api/widget` 每个任务带 `stale`。
- 再次上报后立即恢复为进行中。
- 显示任务每分钟检查一次：除待确认卡片外，24 小时没有上报的任务（已结束的，以及一直没有恢复的可能中断任务）自动清除。方案原文只写了已结束任务；可能中断的任务也一并清除，避免入口长期挂着。

### 4. Skill 与脚本
- 设备 `/skills`（`main/skill.md`）、本机 `skills/mosaico-notify` 与 `.agents/skills/mosaico-notify`（SKILL.md、`references/device-skill.md`、`scripts/progress.py`）同步说明新字段、旧格式拆分规则和“10 分钟没有上报会被标成可能中断”的要求。
- `progress.py`：`--agent` 改为发送 `agent` 字段（不再塞进 `badge`），新增 `--session`；不传 `--title` 时不再发送标题，设备保留原任务名（新卡片默认为 “Task”）。
- `~/.codex/skills/mosaico-notify` 与 `~/.gemini/config/skills/mosaico-notify` 两份全局副本本轮没有改动；它们原本就落后于仓库版本（缺 `--avatar`），继续发送旧格式标题时按冒号拆分，仍能正常显示。

## 四、未验证与已知限制

- 副板灯在可能中断后停止呼吸、确认时显示 alert、完成时显示 success，这些状态截图看不到，本轮没有核对。
- 24 小时自动清除需要等待 24 小时，本轮没有实际观察到。
- 本轮没有做触屏操作，也没有检查网页控制台。
- 喆、體等 GB2312 以外的字仍显示为淡色点。要覆盖繁体和更多人名用字，需要压缩字库包或换其他方案，留给后续处理。
- 任务页页头只统计等你、进行中、已完成，不统计可能中断；列表里有两张可能中断的卡时，页头只显示「1 已完成」。
