# 长文字已读判定修复

2026-10-04，用户反馈长文字在开头、中间、结尾都停留约1秒，仍未读。

旧判定必须从顶部开始、连续覆盖每个区间，下一次start不得超出covered_until+2；跳到中间或末尾直接取消计时。start/end任何一像素变化都会重置计时。它把消息“已看到”变成了无法直观完成的全文覆盖检查。

1.1.11源码改为长短消息一致：消息正文当前可见，松手且惯性滚动结束后静止约1秒即可已读，不要求逐段覆盖全文。至少48px正文可见；不足48px的短正文要全部可见。时分、内边距、仅露出边缘不参与。位置允许4px误差，明显改变范围重新计时；隐藏页面/消息、触摸按住及滚动过程取消本次计时。

按正文对象的真实位置计算可见范围，避免卡片标题停留导致正文尚未显示却已读。更新同一条历史记录read状态，文字灰勾、顶栏未读数量、图片消息提示和GET /api/history均由此产生。图片调用仍使用0..480全屏范围，保持原一秒停留行为。
