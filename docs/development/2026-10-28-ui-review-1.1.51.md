# 1.1.51 界面复查调整

- 普通任务进度更新不再自动切页；任务开始、完成或出错与新消息、新图片仍受自动跳转设置控制，手动切页暂停普通跳转 60 秒，新的确认请求不受暂停影响。
- 任务名按最后一个 `-` 拆出当前任务；确认页优先把状态问题作为主标题，任务名放在头像旁。控制中心等页面的确认提示使用通栏。完成/出错页显示进行中任务入口；没有观察到运行过程的任务不再显示用时。
- 消息空态容器加高；文字截断使用省略号并在末尾标点可通过 1px 字距解决时优先收紧；画面叠加关闭后仍保留页点。镜头出错显示易懂提示并更新底部提示，最近错误码放在设备信息。
- 字库缺字时，同一段文字整体使用已有回退字库，避免清晰和放大字形混排。按需加载原生字形尚未实现：XIP 配置会将内置字库复制到 PSRAM，独立字库需要持久资源及对应的安装流程；设备现有 NOR `ui_apps` 分区只有 1 MiB，而 NAND 文件系统目前只由 Vibe Mode 管理。
- 官方编译成功，镜像 4,427,024 字节；官方 app-update 成功，同一设备 `4553502d4952495301001c2904d0ad2a` 进入 normal，版本 1.1.51，`crash_count=0`，空闲 PSRAM 6,992,336 字节。固件提交 `b2b313f`。
- 未编写或运行测试，未自行验证镜头出帧、页面布局、触摸或文字效果；等待用户体验反馈。
