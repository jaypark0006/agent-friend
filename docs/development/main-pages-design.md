# 图片与推送文字双主页面

2026-10-03用户逐项确认的新设计。本文件记录已确认需求，不表示已安装或实现；当前1.0.4仍是单一主显示区，图片/文字互相替换。实现时遵循本文件，不能把先前单一主页面行为当作最新需求。

- 图片页和推送文字页为并列顶层页面，左右滑动切换；内容后台独立接收，各自保留，不互相覆盖。
- 文字不是设备内部调试日志，而是用户程序推送的内容。按“时分＋内容”追加展示，保留可设置字号与自动折行。时间来源、历史容量与重启后保存策略尚未确认，不把设备启动微秒伪装为实际时分。
- 图片保存最近若干张历史，内容区域上下滑切换。浏览历史时新图继续接收，不强行跳回最新画面；图片历史与高帧率视频的保留规则、容量待实现时明确。
- 文字页上下滑翻看推送历史；主页面上下浏览和顶部边缘下拉设置应分别识别。
- 两个主页面顶部边缘下拉进入设置；设置/子页面底部上滑回到上次所在的主页面。此前“所有界面底部上滑直接HOME”不再适用于主页面历史浏览。
- 每条文字和每张历史图片右上角标记：未读绿色小圆点，已读灰色勾；两类历史分别记录。完整显示并停留约1秒后标记已读，后台收到或快速滑过不算已读。
