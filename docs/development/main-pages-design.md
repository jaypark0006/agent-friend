# 图片与推送文字双主页面

2026-10-03用户逐项确认的新设计。本文件记录已确认需求。2026-10-04已实现并安装1.1.2；具体操作、容量、时间来源、截图和验证见[交付说明](main-pages-and-preview.md)。1.0.4单一主显示区为旧版本行为。

- 图片页和推送文字页为并列顶层页面，左右滑动切换；内容后台独立接收，各自保留，不互相覆盖。
- 文字不是设备内部调试日志，而是用户程序推送的内容。按“时分＋内容”追加展示，保留可设置字号与自动折行。实现采用发送方可选HH:MM，否则SNTP北京时间，未同步--:--；消息32条RAM历史，重启清空，不把设备启动微秒伪装为实际时分。
- 图片保存最近若干张历史，内容区域上下滑切换。浏览历史时新图继续接收，不强行跳回最新画面；照片16张RAM历史，REST逐张保留，WS视频按1Hz留样。
- 文字页上下滑翻看推送历史；主页面上下浏览和顶部边缘下拉设置应分别识别。
- 两个主页面顶部边缘下拉进入设置；设置/子页面底部上滑回到上次所在的主页面。此前“所有界面底部上滑直接HOME”不再适用于主页面历史浏览。
- 每条文字和每张历史图片右上角标记：未读绿色小圆点，已读灰色勾；两类历史分别记录。完整显示并停留约1秒后标记已读，后台收到或快速滑过不算已读。
- 此前1.0.4重力排查后，用户已确认180°文字自动转正；详见180°实体复核JSON。本次保留相同旋转策略，90/270及新手势实体体验仍待用户核对。
