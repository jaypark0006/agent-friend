# LAN Screen 双主页面与截图

2026-10-04交付。最终版本、设备身份、更新操作及验证结果见同目录的`2026-10-04-main-pages-validation.json`。此前1.0.4的“图片文字互相替换/文字裁切/没有截图”属于历史行为。

## 触屏操作

- 图片和推送消息是两个并列主页面，左右滑切换。推送保持当前页面，后台分别接收。
- 图片向下划看更旧，向上划看更新；正在看旧图时收到新图不会跳走。到最新图后恢复跟随。
- 消息上下滚动，每条显示HH:MM与内容；支持16–64字号和左/中/右对齐，自动换行。
- 只有顶边32像素内起手下拉进入设置。设置和子页面底边上滑，返回此前的主页面；内容区上下滑用于历史。
- 状态子页左右滑查看连接、帧率、传感器和API。触屏Wi-Fi扫描及英文密码键盘保留。
- 未读绿点、已读灰勾。静止显示约1秒才标记已读，快速滑过、后台收到、下载历史文件均不标记。长文字需要从顶部开始逐段停留，覆盖完整内容。

## 历史和时间

图片最多16张，文字最多32条，存于RAM，重启清空；满时淘汰最旧项。如果当前查看的项被淘汰，停在仍保留的最旧项。
REST照片逐张保留；连续WS视频最多每秒留一张历史，显示仍使用最新帧队列。视频帧不会无限积累。
消息浏览位置按记录ID锚定，后台追加保持旧位置；在列表底部时跟随新消息。
文字可指定`time:"HH:MM"`，否则采用SNTP北京时间（UTC+8）；未同步显示`--:--`，不把启动时间当时分。网页发送采用浏览器本地时分。
字库支持基础汉字、英文和常见标点；字体从16px位图缩放，Emoji和扩展区汉字没有覆盖。

## API入口

设备地址：[http://192.168.5.61/](http://192.168.5.61/)，IP变化时以屏幕状态页为准。
网页提供完整API清单、照片/文字推送、主页面切换、姿态状态和实时预览。

| API | 用途 |
| --- | --- |
| `POST /api/frame` | 480×480 baseline RGB JPEG，≤256KiB；保留照片 |
| `WS :80/ws/frames` | 一条完整二进制消息一帧JPEG；连续视频按1Hz留样 |
| `POST /api/text` | 追加消息，含text/font_size/align，可选time |
| `GET /api/history` | 两类历史ID、时分、文字及字号、read、未读计数与当前页 |
| `GET /api/image?id=N` | 下载仍在历史中的JPEG，过期404 |
| `POST /api/view` | `page:"image"/"text"/"settings"`；图片可指定id，省略id回最新 |
| `GET /api/screenshot` | 当前完整显示的480×480 BMP |
| `GET /api/info` | 13个端点及容量/格式/时间规则 |
| `GET /api/status` | 页面、连接、历史统计和帧性能 |
| `GET /api/sensors`、`GET /api/orientation` | 传感器及朝下方向、实际旋转角 |
| `WS :81/ws/sensors` | 约10Hz传感器与姿态推送 |

```sh
curl --fail -H 'Content-Type: application/json' \
  --data '{"text":"任务完成\n下一条消息保留历史","font_size":32,"time":"14:26"}' \
  http://192.168.5.61/api/text
curl --fail -H 'Content-Type: application/json' \
  --data '{"page":"text"}' http://192.168.5.61/api/view
```

API ACK表示接收，不表示LCD已完成。帧计数仍使用`received/displayed`；历史ID只在对应通道内唯一。兼容的content_generation字段表示当前通道的历史/消息版本，未留样WS帧的displayed_content_generation为0。

Python客户端位于固件工程`client/mosaico_screen.py`，新增`history()`、`view()`、`screenshot()`和`post_text(...,time_label="14:26")`。

## 截图和性能边界

网页“开始实时预览”约2Hz轮询，停止或隐藏页面后停止轮询。预览频率与设备接收/显示视频帧率不同。
Iris截图通过官方CLI保存PNG，来自实际完成的LCD画面；包含照片叠加标记、消息和设置。
截图使用旋转后的逻辑界面坐标，始终可读，物理MADCTL角度由orientation API报告。
图片截图在安全边界按需复制前缓冲，避免每个视频帧复制；LVGL页面维护局部显示影子缓冲。JPEG解码与LCD DMA并行，捕获时等待当前传输完成。
截图请求串行，临时繁忙返回503；不改设备内容。缓冲合计约900KiB PSRAM。
30FPS仍是目标，JPEG大小、Wi-Fi、上位机生成速度与预览会影响实际帧率，以验证JSON为准。

模拟器通过真实LVGL指针拖动验证消息滚动，同时覆盖横向主页面、设置返回、后台追加锚定、字库和已读计时。
实机REST/WS、截图、历史上下限与长文字已验证；实体滑动手感、90°/270°旋转后触摸仍需用户体验核对。180°自动转正已于2026-10-03由用户确认，本次保留同一旋转策略。
