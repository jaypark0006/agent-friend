复查对象是当前工作区的文件、上游驱动源码、已有构建日志以及实机 1.0.0。此前项目没有 Git 历史，不能还原另一位 AI 所有编辑的逐行差异；以下是能核对的修改，不把文件时间当作完整审计证据。

## 原有修改及判断

- CST9220 驱动：把 `report[0] == 0xAB` 改为空报告，消除了这类空闲报文的格式警告。但驱动同时清空接触点，应用于是把它当作松手，一次滑动可能被切成多个短触摸。这项修复不完整。
- 上下滑阈值降低、边缘区域扩大：方向合理，但手势识别允许底部 y>=400，LVGL 输入拦截却只覆盖 y>=430，且等松手才切页，存在判定不一致。
- 增加 Wi-Fi Back、密码 Back/Cancel 和全局底部返回按钮：有用，提供点击退路。但新 Back 与原 Wi-Fi/Join network 标题重叠，已修正。
- 前次编译及 6 帧推流确实有记录；这些验证不证明真实手势流畅，也不是 30 FPS 验收。

## 本次修改

1. CST9220 本地驱动保留未有新报告时的接触状态：0xAB 返回 `ESP_ERR_NOT_FOUND`，明确的空报告/释放仍表示松手。错误或丢失释放超过 300 ms 后，应用复位接触状态。修复放在版本控制的本地组件，不再依赖修改下载缓存；来源与 Apache-2.0 许可证保留。
2. 单一共享触摸状态机：顶部 96px 下滑、底部 72px 上滑，距离 28px 且纵向位移占优；移动中立即触发，每次接触只触发一次。屏幕切页前重置 LVGL 按压状态。顶部触摸仍可点击按钮，底部按钮仍可轻点返回。
3. 状态四页左右切换：连接、显示统计、传感器、API；设置页增加 API guide 按钮。修复 Wi-Fi/密码页标题重叠。
4. `GET /` 提供中文 API 文档、实时状态、JPEG 文件上传和传感器 JSON；`GET /api/info` 提供实际 URL 清单，区分画面 WS 的 80 端口与传感器 WS 的 81 端口。原有五个 API 保留。
5. 固件版本改为 1.0.1；状态接口使用固件自身版本信息。应用代码、依赖锁、本地驱动和本机页面截图都提交 Git。

## 验证与边界

- UBSan 状态机测试覆盖 ACK 夹在触摸样本之间、28px 即时触发、所有页面返回、消费一次、300ms 超时和 32-bit 时钟回绕。
- 实际 LVGL 页面测试覆盖 Wi-Fi、键盘、密码、连接按钮、开放网络、全局返回和四页循环，查看本机页面截图确认排版。模拟数据不是设备截图。
- 固定 ESP-IDF 构建通过，本地 CST9220 驱动确认进入编译；完整分区表保持不变。
- 实机安装、HTTP/WS 检验见 [交付记录](lan-screen-validation.md)。真实手指手感仍需用户触摸确认，主机模拟不能替代触摸控制器实测。
