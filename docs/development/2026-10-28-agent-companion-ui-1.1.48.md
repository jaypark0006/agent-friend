# 1.1.48 交付记录：Agent 伴侣界面落地

- 交付日期：2026-10-28
- 固件版本：1.1.48
- 硬件目标：ESP-Mosaico（`esp32s31`）
- 设计来源：用户在 Claude 设计画布「Mosaico 随身屏 · Agent 伴侣 UI」（https://claude.ai/artifact/DE83Epp9vqHAdLidiSC5p5，2026-10-28）完成的 16 张画板与规范总览

## 一、落地范围

### 页面与导航
- 主页面从 5 个改为 4 个，左右滑动不循环：此刻 → 任务 → 消息 → 画面；底部页点可点按直达。
- 顶部下拉打开控制中心；控制中心内任意上滑或点「完成」回到最近的主页面。Wi-Fi、镜头、设备信息从控制中心进入，左上角 ‹ 返回控制中心；这些子页底边上滑直接回主页面。
- 删除看板页：电量、网络进顶栏状态条（Wi-Fi 弧线、电量百分比、电池图标；断网灰弧加斜杠，低电量变红，充电时填充变绿）；IP、接口、电池明细、温度、朝向、副板、固件版本进「设备信息」。镜头移入控制中心。

### 此刻页（按优先级只显示一件事）
1. 等你确认：整屏橙色接管，「<Agent> 在等你」、第 k 个/共 n 个、问题标题、说明、两颗 92px 大按钮（L 批准 / R 拒绝）。默认选项 Approve/Cancel 显示为 批准/拒绝，回传给 Agent 的值不变。
2. 1 分钟内完成：绿色笑脸、「<Agent> 完成了」、标题、用时与完成时间；有新图片时出现「看交付图 ›」。
3. 1 分钟内出错（`/api/widget` 新增 `error:true`）：红色叉眼、原因（status）。
4. 工作中：小表情（嘴部方块流动）、Agent 名、已运行时长、标题、当前步骤、56 号百分比、进度条、「还有 N 个任务 ›」。同一任务运行中保持显示，两个 Agent 交替上报不来回切换。
5. 空闲：大表情、96 号时钟、日期星期、「N 条新消息」或「N 张新画面」入口；调暗或 23:00–07:00 显示睡眠表情。
- 断网时显示「没有连上网络」/开机 15 秒内「正在连接网络」与「设置 Wi-Fi ›」入口。
- 标题按 Skill 规范 `<Agent>:<Session>-<Task>` 拆分：冒号前作为 Agent 名，其后作为任务标题；无冒号时用 badge，再缺省为「Agent」。

### 交互规则
- 新确认请求打断主页面和镜头页；在控制中心、Wi-Fi、密码、设备信息页只出顶部橙色横幅，点按进入此刻页。其他任务更新、图片、消息按「自动跳转」偏好切页（原来每次任务上报都强制切到流水线页）。
- 副板 L/R 只裁决屏幕上正在显示的那张确认（按 ID 定向，失效即失败关闭）；不在确认页时按一下先把确认调出来。
- 触控确认在卡片出现 400ms 后才接受；换页或重建时仍按住的手指保持失效直到松开，避免误点到新页面上的按钮。
- 控制中心：大胶囊亮度条（拖动调节，10–100%）、「自动跳转」「灯光提示」两个开关磁贴、Wi-Fi 与镜头入口、设备信息、「长按 2 秒重启」。
- 「灯光提示」（NVS `led_hints`，默认开，`/api/config` 与 WS `config` 可读写）：工作中米白呼吸、等你确认橙色闪烁、完成绿色双闪后弱光保持、出错红色双闪后熄灭、空闲熄灭；关闭后设备不再主动改灯，Agent 仍可直接控制。旧版每次任务上报都把右侧灯关掉的行为一并移除。

### 其他页面
- 任务页：等你确认（深橙底行，点按聚焦到此刻页）、进行中（进度条或流动点）、「今天完成」分组（完成/出错/你批准了/你拒绝了 + 时间）；有变化时就地更新，手指按住或滚动时延后重建。
- 消息页：橙点未读 / ✓ 已读、时间、正文；20/24/32 号消息使用原生字库。
- 画面页：有图时原始画面上叠加「● 时间 · 序号 / 总数」胶囊和底部页点，可点页点跳页；无图时显示控制台网址二维码（LVGL QR）、IP 和提示卡片。
- Wi-Fi：已连接网络高亮带绿色 ✓、锁形图标/无密码、四格信号；密码页为自绘键盘（字母/数字/符号三层、⇧、删除、橙色「连接」键），少于 8 位提示「密码至少 8 位，现在是 N 位」。
- 镜头页：实时画面上叠加「‹ 控制中心」和「镜头开着 · 离开这页就关」。

### 字体与主题
- 新增 Noto Sans SC 原生子集：常规 20/24/32、粗体 24/32（GB2312 一级汉字 + 界面全部用字，共 4108 字形；粗体 24 为界面用字 568 字形）及粗体 56/96 数字，由 `projects/lan_screen/tools/gen_ui_fonts.py`（lv_font_conv 1.5.3）生成；生僻字回退到原 16px 放大字库。来源与哈希见 `main/SCREEN_FONT_PROVENANCE.md`。
- 颜色、字号、间距集中到 `main/screen_theme.h`，页面不再写死色值；表情为 9×7=63 个方块（`screen_avatar.c`），切状态只改颜色，同屏最多一处循环动效，手指按住时静止。

### API 兼容
- `/api/view` 新增 `now`、`tasks`、`picture`、`messages`、`control_center` 名称，原 `status`/`dashboard` 指向此刻页，`widget`/`pipeline` 指向任务页。
- WS `page.changed` 页面名：此刻页为 `now`（原 `dashboard`），新增 `wifi_password`、`device_info`；其余不变。`/api/status` 的 `page` 字段保持旧值（此刻页仍报 `status`）。
- `/api/widget` 新增 `error` 字段；`color` 仍接受，但屏幕只按状态着色。
