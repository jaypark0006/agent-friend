- 设备页 `#view`：屏幕、切页控制、未读状态、设备信息、实时传感器和子板控制同页。快速设置预留一个小区域，自动切换用一个立即保存的checkbox。取消独立首页和网页设置页，旧`#home/#settings/#status`路由兼容到此页。
- 传感器一开关：勾选立即连接统一`ws://IP:81/ws/sensors`，服务端连接后直接推送，无额外subscribe操作；自动重连并提示断开。关闭即停止订阅并保留最后值。核心数值直接可见，原始JSON和性能诊断默认折叠；麦克风/摄像头采集各一个checkbox。进入设备页默认开启读取型WS，不自动打开采集硬件。
- 推送页 `#send`：图片、文字两栏同时可见，不再选择类型或展开编辑器。图片粘贴/拖放与转换预览合一，文字支持字号、对齐、时分及Cmd/Ctrl+Enter发送；排版示意折叠。
- 图片发送默认`/ws/frames`，一次发送一个JPEG，收到`{accepted:id}`就显示已接收。失败/断开/超时明确未确认，不自动重复发送或回退HTTP；不轮询计数推断接收。不把接收回执当已显示或已读。文字继续用`POST /api/text`的接收回执；两类最近8条本页记录同列展示，具体结果在发送按钮旁显示。
- HTTP页：预填请求示例下拉、method/path/设备或Mock/执行一行完成，不再双栏集合和空白引导；Headers/Body、Mock模板、响应Headers默认折叠。仅点击执行发请求，Mock仍完全在浏览器中并明确标记。
- 新功能 `#camera`：设备本地摄像头色块，独立页面，详情见[摄像头色块](camera-color-blocks.md)。
