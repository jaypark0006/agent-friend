# 随身屏任务通知技能

2026-10-07，用户要求将Mosaico作为默认随身显示器，在Codex任务完成时推送文字与合适配图，并适应IP变化。

技能源码位于 `skills/mosaico-notify`，安装到 `~/.codex/skills/mosaico-notify`。本机全局AGENTS加入收尾调用指引；不是后台事件监听器，已运行且未加载新指令的会话不保证自动调用。新会话可自动发现，也可显式 `$mosaico-notify`。

通过现有1.1.26 HTTP API，先文字后图片，默认显式切图片页，不改NVS自动切换开关；文字留在独立消息页。配图默认为Pillow绘制480×480状态卡，也可把图像生成工具产物放入卡片。JPEG三分量baseline≤256KiB，文本≤1024 UTF-8字节。

IP按ARP目标MAC、成功地址缓存、旧地址候选、当前本地网段（最多256地址）寻找，必须同时匹配MAC与/api/info app=lan_screen。MAC来自官方状态的hardware_mac，尚未经本技能核对实际Wi-Fi接口；不匹配时停止，不能误认其他LAN Screen。大网段、跨网、客户端隔离需用户提供直连地址或同网；未部署公网中继。MAC匹配防误投，不替代鉴权。

依赖macOS系统网络命令、中文字体PingFang、Python3及Pillow。技能要求优先现成Python运行时，缺依赖不擅自全局安装。脚本无自动重发，部分成功与未知结果明确输出，accepted不等于显示/已读。

本次仅创建、安装和Git提交技能，没有执行脚本、技能验证器、设备试推或生成样例图片；没有修改固件，无需编译刷入。未来按用户授权发送真实任务通知不属于测试。效果仍待用户实际使用反馈。
