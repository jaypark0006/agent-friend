# 自动切换

> 版本专题/历史记录：文中版本、授权、待办和验收描述对应当时，不代表当前状态。最新功能、API、架构与重构计划见[当前文档索引](../../vendor/esp-mosaico-vibe/projects/lan_screen/docs/README.md)。


2026-10-04，1.1.16：按用户最新要求，图片和文字共用一个“自动切换”复选框，不再分类型配置或展示两套策略。

- 勾选：新文字切到文字页并显示该条开头；REST照片或WS画面切到图片页并跟随最新画面。连续画面已在图片页播放时继续刷新，不反复重建页面。
- 取消：保持当前页面，后台接收并保留历史，提示未读。文字页底部增加图片未读数量，图片页保留文字未读提示。
- 设置/配网期间不跳出，拖动和文字惯性结束后再执行。多个等待中的推送以最后一个为准；显式/api/view优先并取消之前待处理的自动请求。
- 改回关闭取消待处理请求；勾选只影响后续到达的内容。开关重启保留，沿用旧NVS设置，旧版已选自动文字的设备升级后同一个开关也作用于图片。

设备：顶部下拉设置，直接勾选“自动切换”，立即保存。网页：设备设置，一个同名复选框，勾选/取消立即保存，无额外保存按钮。两边操作同一个配置，读取真实保存状态。

```http
GET /api/config

POST /api/config
Content-Type: application/json

{"auto_switch":true}
```

关闭发送 `{"auto_switch":false}`。GET/POST响应含auto_switch布尔值；/api/status同样提供。旧字段new_message_action的keep/switch仍作为同一个开关的兼容别名返回和接受，含义已扩展至图片与文字；同时传两个字段时必须一致，参数非法400，NVS保存失败500。不增加按图片/文字分别保存的设置。

网络任务只登记导航目标，显示任务在安全时机处理，保留原有页面滑动动画；LVGL与LCD仍归显示任务所有。配置写入完成才更新运行中状态。网页保存结果不确定时禁用操作、提示重新进入读取真实状态，不冒充已保存。

1.1.16已通过官方CLI编译并安装。本轮未新增/修改测试文件，也未运行单元测试、模拟器或基准。在用户本次重申全局禁止自测前，已进行了REST/WS实机检查；最新要求到达后停止后续自测，今后由用户测试并反馈，历史验证授权不延续。
