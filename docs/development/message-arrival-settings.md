## 行为

- `keep`（默认）：保持当前页面，消息继续追加到历史。照片右下方显示信封和未读数量，绿色有未读、灰色为0；其他页面显示绿色未读数量。文字页继续使用原逐条绿点/灰勾与阅读规则。
- `switch`：新文字到达自动切到文字页并显示该条开头，长文字不会直接跳到末尾。手指拖动或惯性滑动结束后执行；设置和密码输入期间保留请求，退出后显示最近推送消息。
- 开启自动切换只影响随后到达的文字；改回keep取消尚未执行的自动请求。显式`POST /api/view`取消此前待处理的自动切换，继续作为独立导航命令。
- 图片/WS视频继续后台接收，不主动切页。两类历史仍独立保留，不因切页互相覆盖。

## 设置入口

设备顶边下拉 → Messages → 选择“保持当前页面 + 未读提示”或“自动切换到文字页”，立即保存。网页提供相同选项和保存按钮。独立NVS命名空间`lan_screen`、键`auto_messages`持久保存；默认keep，不改Wi-Fi配置。保存失败时报告错误并维持原策略。

```http
GET /api/config
```

返回`{"new_message_action":"keep"}`或`{"new_message_action":"switch"}`。

```http
POST /api/config
Content-Type: application/json

{"new_message_action":"switch"}
```

返回已保存设置；改回keep使用`{"new_message_action":"keep"}`。无效字段/值返回400，保存失败500。`/api/status`包含new_message_action，`/api/info`列出配置端点。

## 实现与状态

`screen_preferences.c`拥有配置加载、保存和HTTP处理，触屏与HTTP修改通过应用锁串行。网络接收只登记自动导航请求，显示任务在安全时机应用；LVGL/LCD始终由显示任务操作。新文字默认不会触发导航。
