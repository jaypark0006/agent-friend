## 入口与布局

首页为两张入口卡：“查看设备”“推送内容”，附当前设备页面、文字未读数和刷新统计。左侧导航提供首页、查看、推送、设置、HTTP Try，移动端变为顶部导航。浅色卡片、深色导航、设备画面框，内置SVG图标和系统字体；不加载外部字体、CDN、框架或构建工具。

查看页提供设备画面、快速切换图片/文字/设置页、Wi-Fi/IP、电量/朝向和未读数量。画面需点击“获取画面”，实时预览默认关闭，开启后约2Hz请求截图；离开查看入口、切到后台或离开网页时停止。

性能明细、传感器与采集、原始JSON、内容历史默认折叠。传感器以卡片呈现加速度/角速度/双磁场、AI/BOOT、音量表和摄像头状态；打开查看入口才连接传感器WS，约10Hz收到数据、最多5Hz更新DOM，连接失败时退回REST快照并延迟重连。缺失能力明确显示“当前固件未提供”，不开启摄像头或麦克风；采集需要用户点击开启按钮。WAV/原始UYVY下载保留既有API语义。

历史展开才读取，图片/文字在历史卡里切换，显示时分与已读标记。文字按纯文本展示；历史图片点“查看图片”才下载，也可请求显示指定历史图。所有历史来自设备RAM，不生成假历史、不自动下载所有图片。

发送页默认只显示图片/文字两个选择，编辑器尚未展开。图片支持文件、拖放、Cmd+V/Ctrl+V，复用image-upload.js在宿主浏览器转换480×480、baseline三分量、256KiB以内JPEG；保留完整显示/中心裁切、预览、保存处理结果和发送进度。收到剪贴板图片只在发送入口处理；不会干扰HTTP编辑器或普通文字粘贴。转换有generation隔离，过期结果不覆盖新选择；发送中禁止更换。粘贴/转换不会自动发送。

文字为空开始，提供主动“填入示例”、16–64字号、对齐、UTF-8字节计数和排版示意；时间设置折叠，空时间由设备SNTP决定，可填写HH:MM。发送前校验字节和字号，仅点击推送才POST。排版预览明确为示意，不宣称与设备字库/换行一致。

设置独立入口，读取设备消息到达策略后才允许保存，默认“保持当前页面”，可选“自动切文字页”；保存复用/api/config，错误可见，不把失败写成保存成功。Wi-Fi仍在设备触屏上配置。

## HTTP Try

独立工作台，左侧集合分查看与发送/控制；初始不选择请求、不展开编辑器。选择预置请求或“创建空白请求”后显示方法、路径、目标、执行按钮。请求参数、Headers、Body、Mock模板和响应Headers默认折叠；选择预置不会发送。

预置覆盖status/sensors/orientation/history/screenshot/config/buttons/microphone/audio/camera/frame/image/info及POST text/frame/view/scroll/config/采集开关。可修改GET/POST/PUT/PATCH/DELETE、路径/查询串、Headers JSON；Body支持无、JSON、文本、已转换图片、原始文件。提供PUT等方法是通用调试能力，不表示设备已有对应路由。文件限4MiB；推图仍由设备约束为256KiB合法JPEG。

“真实设备”只接受同源URL或相对路径，不允许其他目标、URL内账号/密码或片段，重定向报错。按执行才请求；执行期间锁定当前编辑器，防止请求和结果串到其他示例。超时15秒，响应读取最多4MiB；错误响应同样展示status、Headers和内容。

“本地Mock”返回可编辑的status/headers/body模板，不执行本次设备请求；响应显著标注本地Mock。控制台顶部普通状态查询独立运行，切换Mock不把设备卡片变成模拟设备。预留Mock包含请求体与响应体，二进制截图/音频/摄像头示例返回明确占位JSON，不伪造硬件画面或连续录音。Mock模板不会自动执行、也不会代替真实传感器数据。

响应显示HTTP状态、耗时、大小；JSON格式化，文本原样展示，图片预览、音频手动播放、其他二进制展示前256字节hex并可下载完整响应。可复制文本响应；普通HTTP局域网页无法使用Clipboard API时提供复制回退。图片/音频不自动播放/执行HTML；所有设备文字与响应文本经textContent展示。

## 生命周期与资源

首页只轮询只读status（约3秒，防重入），查看入口按需WS/REST；截图、历史、编辑器和调试请求默认不运行。隐藏时停止轮询/WS/实时画面，但不因为切换浏览器标签中止用户正在发送的写入；离开网页时清理定时器、WS、活动请求与Blob URL。中止/超时不能保证服务器没有接收POST，错误文案不宣称写入失败已回滚。

CSS、UI逻辑、请求引擎/预置分文件：main/api.html、console.css、console.js、console-api.js。静态资源由HTTP本地提供并嵌入应用二进制，注册容量从24增为28，现有API协议/分区/OTA契约未改变。资源不需写入独立文件系统，下一次授权编译更新会一起安装。

没有新增测试或依赖工具链，本轮没有运行JavaScript、启动应用、浏览器自动验证、编译、刷机或实机操作。之前1.1.12新增camera/esp_video依赖仍待下一次授权编译解析并提交锁文件；届时核对缓存sdkconfig版本/开关。
