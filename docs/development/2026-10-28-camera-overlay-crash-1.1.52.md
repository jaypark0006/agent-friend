# 1.1.52 镜头画面文字叠加崩溃修复

- 用户反馈点击镜头后设备关机。设备重新上线后显示看门狗重启、`crash_count=1`；保留的 Core Dump 与 1.1.51 固件 ELF 哈希匹配，显示屏幕线程位于镜头画面的文字叠加及 LVGL 字形位图读取。转储不含可核对的 Boot ID，不能证明其与该次故障完全对应。
- 代码确认叠加绘制设置 `req_raw_bitmap` 后调用 `lv_font_get_glyph_bitmap(..., NULL)`；LVGL 9.5 的该包装函数会清掉原始位图标志，然后字体读取会解引用空 draw buffer。1.1.52 改为直接调用支持原始位图的字体回调，且画字与测宽使用相同的整段字体选择。该绘制代码同样用于图片画面的文字叠加。
- 转储和解码结果由官方 `mosaico.py iris crash --archive` 保存在项目会话 artifacts；固件提交 `be4df6d`。
- 官方编译成功，镜像 4,427,024 字节。官方 app-update 安装成功，同一设备 `4553502d4952495301001c2904d0ad2a` 返回 normal、1.1.52，`crash_count=0`，当前空闲 PSRAM 6,992,388 字节。
- 未运行测试、未自行进入镜头页或验证出帧及画面效果；需要用户体验反馈。动态按需字库仍未实现。
