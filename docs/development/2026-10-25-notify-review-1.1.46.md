## 待修复问题

1. P1：screen_widget_trigger_action_by_index 在指定卡片失效、已裁决时仍回退到首个待确认任务。触控事件与后台任务更新交错时可能裁决其他任务。应仅允许实体按键的显式无目标调用回退；指定目标必须失败关闭，并优先使用稳定任务 ID，在同一锁内完成定位和修改。
2. P2：progress.py 先发布确认卡片再连接 WS；连接窗口内的事件会丢失，最迟等待约 120 秒后 HTTP 回退才能读取。应先连接后发布。
3. P2：WS 超时、断开或异常被吞掉后进入每 0.5 秒无限 HTTP 轮询，与“无需轮询”的技能说明不符。应有明确的超时错误与退出边界。
4. P2：手写 WS Pong 未使用客户端掩码、未回显 Ping 载荷，可能遭服务端断开；握手未校验 Accept。应使用完整协议实现或补齐协议处理及 finally 关闭。
5. P2：设备 /skills LED 示例使用 preset 且缺少 slot，而 screen_interact_http.c 要求 slot 与 effect，照抄会被拒绝。正确示例为 {"slot":"right","effect":"breathe"}。
