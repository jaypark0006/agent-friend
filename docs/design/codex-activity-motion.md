# Codex 活动屏：纯三维动画样稿

2026-10-08。用户否定首版文字状态卡、线框光球的视觉方向，明确要求动画本身表达活动，设备画面无需文字。本轮替换[动作样稿](codex-activity-motion.html)，使用实际Three.js三维渲染。预览动作按钮与连接状态提示均在480×480画面外。

## 视觉方向

主体是一件有连续曲面、金属反射和虹彩的液态结。用可变形的参数曲面表现从交织到舒展的过程，GPU计算曲面与法线；程序化摄影棚环境反射、景深方向上的小液滴和Bloom提供体积感。素材均由代码生成，无外部模型、贴图或文字叠加。

| 事件 | 形体与动作 | 结束行为 |
| --- | --- | --- |
| working | 交织的液态结缓慢流动，冷色金属反射 | 持续，直到新状态 |
| insight | 收紧蓄力，曲面解结舒展成开放轮廓，暖光与少量火花释放 | 默认3.6秒，回到工作 |
| waiting | 放缓并稍微舒展，低速悬停 | 持续，直到新状态 |
| done | 收束为完整平滑环，液滴归隐，逐渐安定 | 停在完成结果 |

“顿悟”应由明确报告关键发现的事件触发，不能根据内部思考、普通输出增量或文字关键词就认定有突破。正式接入须给瞬时事件加event_id去重；完成、失败、待用户处理应优先于短暂动效。当前未设计失败动作，不生成虚构百分比。

## 独立程序方向

保留用户提出的独立程序：通过不同适配器接入Codex、其他agent或普通程序，将来源事件统一成活动状态，再驱动动画并推流到Mosaico。事件来源、选择展示哪个任务、可用管理操作与视觉渲染各自独立。观看已有会话与由程序启动并管理会话需按各来源能力区别实现，不能将App Server存在视作能任意接管桌面现有会话。

当前仍是视觉样稿，未实现常驻程序、活动监听、任务管理、JPEG推流或断线恢复。程序与设备之间拟沿用现有480×480 JPEG WebSocket链路。

## 实现与边界

- Three.js固定0.180.0，静态模块从esm.sh载入；Shader曲面、MeshPhysicalMaterial、PMREM环境贴图、UnrealBloomPass与OutputPass。
- 480×480渲染分辨率；暂停、系统减少动态效果偏好、离屏/隐藏暂停；未承诺实机帧率或功耗。
- 加载失败或WebGL2不可用时在画面外如实提示，无文字状态卡回退。
- 本轮没有修改固件、编译刷入、运行测试、启动浏览器或进行设备效果验证。样稿供用户自行查看，尚未通过运行验收。
