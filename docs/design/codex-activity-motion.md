# Codex 活动屏动作样稿

2026-10-08。用户希望把实时 Codex 活动流式传到 Mosaico，并为“顿悟”等时刻提供固定视觉效果。本轮提供可交互视觉样稿，源文件为 [codex-activity-motion.html](codex-activity-motion.html)。样稿使用 Canvas 2D 表达动作节奏，没有外部依赖；正式渲染器可根据后续视觉选择使用 Three.js。

## 动作约定

| 事件 | 表现 | 结束行为 |
| --- | --- | --- |
| working | 光核轻缓旋转，或线索散点轻缓漂移 | 持续，直到新状态 |
| insight | 汇聚、核心亮起、光环扩散；另一方案将散点连成星图 | 默认2.8秒，自动回到working |
| waiting | 降低运动速度，明确“等待你” | 持续，直到新状态 |
| done | 外圈收束，画面逐渐安定 | 停在完成结果 |

“顿悟”表示一次明确报告的关键发现或方案突破，不等同于任务完成。建议正式接入时使用显式 `insight` 事件并带 event_id 去重；不能将模型内部思考、普通输出增量或文字关键词自动当成已确认突破。任务结束、失败、等待用户应以可靠的活动状态为准，优先于短暂动效；失败动画暂未设计。不生成虚构百分比。

正式传输方向仍为 Codex 可用活动源 → Mac 实时渲染480×480 → JPEG WebSocket → 设备。活动源、常驻程序、编码背压、重连、设备身份匹配以及正式推流尚待实现，当前样稿未连接 Codex 或设备，也没有网络请求。

## 样稿范围

- 提供“光核展开”“思路连成星图”两种方案，按钮切换状态和重播顿悟；控件在480×480内容区域之外。
- 单次柔和扩散，不做全屏闪白；支持暂停、系统减少动态效果偏好，隐藏或离屏时不推进动画。
- 完成与顿悟有不同结束状态。所有文案是视觉样例，不代表实时任务事实。
- 本轮只新增设计样稿及说明，未修改固件、编译刷入、运行测试或进行浏览器/设备效果验证。内联样稿供用户自行查看。
