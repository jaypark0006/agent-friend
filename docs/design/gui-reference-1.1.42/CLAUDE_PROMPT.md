# 可直接交给 Claude 的任务描述

我想重新设计 ESP-Mosaico 随身屏上 **LAN Screen 1.1.42** 的 GUI。请阅读附件参考包，先完成设计，暂不改固件、不运行测试或模拟器、不刷机，也不要自行操作设备、摄像头或实体按键。

这是一块 **480×480 的独立触摸屏**，目前使用 C + LVGL。核心用途是放在桌面或随身查看 AI Agent 的任务进度、确认操作、接收图片与消息。请围绕小屏快速扫读和触控重新组织视觉层级、信息密度与导航。

附件中的最新真机图只有 `01-media-empty-current-1.1.42.png`。其他图片明确标为历史设备截图或历史模拟器图片；**当前页面结构与行为以 README 和 source/device 中的 1.1.42 源码为准**，不要把所有图片当成同一版，也不要把补绘画面称为真实截图。

请先重点设计四组界面：

1. **Dashboard**：在线与电量、设备地址、少量有用状态；让用户一眼知道是否可连接、是否需要充电。
2. **Pipeline**：同时展示多个任务的标题、当前步骤、进度与完成历史；包含普通任务、无百分比任务、已完成任务、等待确认任务。确认态保留 `[L] Approve` 和 `[R] Cancel` 与左右实体键的对应关系。
3. **Messages**：中文与英文消息、时间、未读/已读、长文本滚动；展示短消息和长消息两种内容。
4. **Control Center**：亮度、自动切换、Wi-Fi 与少量工具；明确返回方式，降低误触重启等操作的可能性。

随后补齐 Media 的有内容/空状态、Camera 的运行/不可用状态、Wi-Fi 列表、密码键盘，以及全局低电量与断网状态。

请提供：

- 两个有明显差别的视觉方向，各用一段解释它适合这台设备的原因；不要仅更换主题色。
- 选一个推荐方向，输出上述四组的 **480×480 无设备外框设计图**；Pipeline 同时给普通状态和待确认状态。
- 一张页面与导航关系图，说明顶栏、页点、返回、纵向列表和左右切页如何协调。
- 一套精简设计规范：字号层级、边距、圆角、颜色语义、图标、触控区域、状态反馈和低成本动效。
- 每张图标明真实内容与示例数据；说明哪些元素可直接用 LVGL 实现，哪些需要额外资源。

优先保证实际可读性与触控，不要把桌面管理后台缩进小屏。不要依赖复杂模糊、玻璃叠层、整屏持续动画或额外常驻大图。保留任务就地更新、滚动位置记忆、用户阅读历史时不抢焦，以及图片/消息自动切换设置的既有语义。

设备支持重力旋转；摄像头已有安装旋转/镜像校正，请不要为了新视觉修改这些行为。30 FPS 是目标，不是已验收承诺。素材里的健康文案、示例状态和硬编码规格不能作为实机事实。

本轮以设备 GUI 为主；`source/web/` 只是电脑端控制台的补充背景。若提出 Web 方案，请另列，避免混进 480×480 设备页面。
