# Agent Friend 使用指南

适用版本：1.1.58。适用于已经装好固件的 ESP-Mosaico；本机设备已完成安装与版本确认，界面和交互效果由你实际使用后反馈。

## 打开控制台

1. 在设备顶部下拉打开控制中心，连接 Wi-Fi。
2. 让手机或电脑连接同一局域网。
3. 在浏览器打开设备 IP。本机目前为 **[http://192.168.5.92/](http://192.168.5.92/)**；换网络或地址变化时，从顶栏或设备信息查看新 IP。

普通使用不需要打开开发终端或保持 USB Gateway 会话。设备需要供电并保持联网。

## 先用这三个入口

**[此刻](http://192.168.5.92/#now)**：查看当前最需要关注的任务。待确认请求优先显示为橙色主卡，下面可查看任务状态；需要时打开随身屏画面预览。

**[推送](http://192.168.5.92/#send)**：输入文字并选择字号后发送；Mac 可直接粘贴截图，也可选择图片，在预览中选择完整显示或中心裁切后发送。历史缩略图可再次选择「在随身屏显示」。

**[设备](http://192.168.5.92/#device)**：设置自动跳转、画面角标和灯光提示，查看电量与传感器，或选择灯光效果。「自动跳转」决定新任务、图片或文字到来时是否切到相应页面；关闭后可手动查看内容。

[开发者](http://192.168.5.92/#dev)中的 HTTP、WS、模拟 Agent 和镜头工具按需使用，日常看进度、发图片和处理确认都可以从前三个入口完成。

## 设备上的手势和按键

- 左右滑动：依次切换此刻、任务、消息、画面，首尾不循环。
- 顶部下拉：控制中心，包括亮度、Wi-Fi、镜头和设备信息。
- 任务待确认时：按屏幕上的选项，或按交互副板的 L / R 键；具体操作以卡片显示的选项为准。网页上的批准/拒绝也会给 Agent 发送同一任务的事件。

## 让常用 AI 助手自动显示进度

将下面这段交给你的助手；地址按实际设备 IP 调整：

> 请先读取 http://192.168.5.92/skills，然后把这个随身屏接入当前会话。每轮任务用独立 ID，同一任务持续更新，agent 写你的名字，session 写固定会话名，title 只写任务名。开始和关键步骤更新进度，结束标记 done；长任务至少每几分钟上报一次。需要我决定时，先连接 /ws/hub 监听，再发送该 ID 的确认卡，并等待实际批准或取消。超时或断线不得视为批准。

助手需要能访问你的局域网。不能访问本机网络的远端助手可由本机的客户端或 Agent 接入。已有脚本使用方式见[通知技能](../skills/mosaico-notify/SKILL.md)，无需为日常操作编译固件。

## 使用中会遇到的状态

- **可能中断**：任务超过 10 分钟未更新，不代表设备坏了；助手再次上报即可恢复。
- **没有任务**：此刻页显示空闲时钟；连接助手并让它上报后出现任务。
- **历史消失**：任务、图片和文字存于 RAM，设备重启后清空；图片最多 16 张且合计受 1 MiB 限制，旧图片会被淘汰。
- **网页没有完整打开**：1.1.58 在启动 8 秒未就绪时最多自动重载一次，仍失败会提示重新加载。如果反复发生，反馈浏览器、设备 IP、大致耗时和所停留页面即可；该兜底不代表首屏问题已经通过验收。
- **缺字显示淡点**：当前字体覆盖范围有限，缺失字形不会以方框展示；可反馈具体字符。
