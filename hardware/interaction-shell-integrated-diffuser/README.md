# square4 前壳一体均光薄膜版

2026-10-19。根据用户实拍反馈 IMG_5399.HEIC，停止继续调整四片独立均光件；直接修改用户原始 `ESP-Mosaico_Module_Interaction_square4-3D.3mf` 的前壳，在四个 LED 孔的正面增加 **0.40 mm 一体薄膜**。

本版不是给旧壳塞入的附件。需要重新打印修改后的前壳；已打印的原后盖继续使用。

## 选用一体打印的原因

| 方案 | 打印和安装特点 | 本次选择 |
| --- | --- | --- |
| 一体薄膜与前壳一起打印 | 正面朝下时，薄膜从平台 Z=0 起打印，不悬空；没有小插片安装、倾斜和掉落问题 | **本次交付** |
| 改成整条均光板凹槽 | 一条插片比四片方便，适合更换材料；仍需要固定或锁止结构，拆除四孔之间结构也会改变隔光条件 | 本次未生成，避免继续引入插片公差问题 |

薄膜放在**最外侧、与前壳正面齐平**，而不是放在内侧高处当作跨孔顶板。打印从这面开始，新增薄膜本身没有支撑接触面；与加在悬空位置再搭桥的做法不同。

原模型的内部隔墙、两个键位、PIR、光敏、红外、后盖和卡扣几何均未因添加薄膜而重建。改动只是在四个前灯孔处增加材料，使用布尔并集将其连入原前壳。

## 下载与打印对象

- **只需重打前壳：** `print-files/square4_front_integrated_diffuser_040mm.3mf`，只有一个修改后的前壳对象，已按正面贴平台摆放。
- 对应 STL：`print-files/square4_front_integrated_diffuser_040mm.stl`。同样是完整前壳，不是独立薄膜。
- `print-files/square4_complete_integrated_diffuser_040mm.3mf`：修改后前壳＋原后盖，两者是独立物体，已平放排版。后盖几何来自原文件，没有改尺寸；已有后盖时不必重复打印。
- `square4-integrated-shell-diffuser-040mm.zip`：完整包，包含模型、说明、生成器、结构图和建模信息。

所有文件单位为毫米；3MF 是模型文件，不包含打印机配置、G-code 或原工程中的装配指南。

## 默认打印方式

沿用此前用户选择的 **白色 PLA、0.4 mm 喷嘴**。如改用其他材料，透光表现需以实际耗材为准。

1. 保持 **100% 比例**和文件中的方向，**有四个均光面的正面贴平台，壳体内腔朝上**；不要翻成内腔朝下。
2. 建议首层 0.20 mm、层高 0.20 mm，新增薄膜对应最开始的两层。使用实心顶/底面，例如顶/底层数不少于 3；不要把第一层设置为 0.28 mm 后误以为总厚仍是两层 0.40 mm。
3. **新增均光面不需要支撑。** 其余原壳结构的打印设置沿用原来适合该壳体的配置；不要因为这句说明就强制删除原来其他部位需要的支撑。
4. 均光面直接接触打印平台，所以表面会带平台纹理；想要平滑表面可使用适合白色 PLA 的光面平台。是否换平台由用户决定，不承诺光面或纹理面哪种均光效果更好。
5. 不需要安装旧 V1 / V2 / V3 四片均光件。打印结束后使用修改后的前壳装配设备。

0.40 mm 是整片中央透光厚度，周围原壳保持其厚度以承载和隔光。白色 PLA 颜料与首层挤出会影响透光率；一体打印意味着不能像插片那样独立更换均光材料。

## 来源、构造与交付边界

- 源文件 SHA256：`8ee0478b84d0025c83cbcb69b60c0c7910d99190452fc00aada208974aa509da`。
- 前壳网格：`3D/Objects/object_5.model`；后盖：`3D/Objects/object_6.model`。
- 原前壳正面 Z=-5.44999981 mm，原始工程也将其平移到打印平台 Z=0。本版保留这个方向。
- 四个薄膜补片的局部中心 X=-16.8875 mm，Y=16.88247 / 5.62749 / -5.62749 / -16.88247 mm；补片宽 9.75、长 9.85、R1.80 mm，覆盖原外侧倒角口并与边缘重叠。模型并集后，重叠部分属于原壳厚边，实际中央膜片厚 0.40 mm。
- 保留前壳原外形约 44.90 × 44.90 × 10.90 mm。具体建模输出与来源记录见 `print-files/model-information.json`。
- 只完成原网格读取、布尔建模及文件生成。**没有运行切片器、模拟器、打印机或实物装配、光学效果测试。** 建模器成功导出不代表打印与均光已经实测通过。
- 实拍图用于判断问题与安装位置，没有根据照片像素比例推算尺寸，也没有复制照片进入交付包。

打印方向参考：[Prusa 对桥接的说明](https://help.prusa3d.com/article/poor-bridging_1802) 建议通过改变方向尽量消除桥接。本版将均光膜放在平台上，从几何上消除新增薄膜的悬空；这不是实机切片报告。

## 重建模型

Python 3.12 环境安装 `requirements-modeling.txt` 中的依赖后运行：

```sh
python3 hardware/interaction-shell-integrated-diffuser/generate.py --source /Users/qilei/Downloads/ESP-Mosaico_Module_Interaction_square4-3D.3mf
```

默认 `--thickness 0.40`；生成器会核对源文件 SHA256，避免把坐标误套到圆孔版本或其他修改版壳体。只生成新文件，不覆盖下载目录原文件，不启动切片或打印任务。
