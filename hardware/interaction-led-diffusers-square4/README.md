## 打印与固定

适用：FDM、0.4 mm 喷嘴、白色 PLA。建议 **0.20 mm 层高及首层、2 道墙、100% 实心、至少 4 层顶/底面、平放、无支撑**；温度沿用所用 PLA 的正常配置。0.80 mm 厚度对应 4 层。

此 square4 版本是四个贯通的方孔，内侧窄段没有托住薄板的完整槽底。本套采用间隙配合，不能靠过盈或卡扣自锁。应在壳体内侧定位后，侧边少量点胶固定；不要让胶覆盖透光区域，也不要把板压在 LED 上。若已有原装光学镜罩，安装占位需以实物为准。

单边 0.20 mm 间隙和 0.80 mm 板厚是本次设计值。白色 PLA 的配方、打印精度及层间状态会影响松紧、透光和光斑，未保证消除热点或替代原装光学透镜。

**本次仅生成模型与交付文件；没有启动切片器、打印机或设备，没有做打印、实物装配或透光测试。**

## 参数调整

生成器仅使用 Python 标准库，可根据用户后续实物反馈调整参数：

```sh
python3 hardware/interaction-led-diffusers-square4/generate.py --clearance 0.20 --thickness 0.80
```

`--clearance` 表示单边间隙；默认 `--chamfer 0.15`。生成器不启动切片或发送打印任务。
