# square4 V3：作为独立对象新增的定位均光件

2026-10-17。保留用户的 square4 外壳，**只新增均光件**。3MF 内有四个独立对象，每个对象是“薄透光面＋中空定位圈＋台阶挡边”的一体打印件。没有修改或复制原壳体，也不需要重新打印外壳。

## 直接使用

- **已有外壳工程：** 导入 `print-files/square4_v3_locating_diffuser_1pc.stl` 为新对象，复制四份。四件相同，可互换。
- **单独打印四件：** 打开 `print-files/square4_v3_locating_diffusers_4_objects.3mf`，四个对象已平放排成两行，不包含外壳。
- 不是给旧小平片补救的独立粘接框：这四个新件各自已将定位圈、透光面和挡边连成一个连续实体，直接替换旧平片。

## 结构与尺寸

前孔 8.05 × 8.15 mm；后方台阶凹位名义尺寸 9.55 × 10.15 mm；台阶局部坐标 Z=-2.85 mm。来自原 `ESP-Mosaico_Module_Interaction_square4-3D.3mf` 前壳对象 `3D/Objects/object_5.model` 的截面和顶点测量。两端周围有局部连通缺口，因此不是把所有周围结构都视为完全相同。

| 部位 | 尺寸 / 功能 |
| --- | --- |
| **中央透光面** | **0.40 mm 厚**，没有叠加定位圈实体 |
| 后方挡边最大外形 | 9.25 × 9.85 mm，R0.80；与后凹位名义单边间隙 0.15 mm |
| 前方定位圈外形 | 7.85 × 7.95 mm，R0.85；与前孔名义单边间隙 0.10 mm |
| 定位圈高度 | 0.80 mm，伸进原有小孔帮助居中、减少自由歪斜 |
| 定位圈壁厚 | 0.50 mm，中间保持空心；中央膜片仍只有 0.40 mm |
| 定位圈入口 | 顶部 0.20 mm 高范围，每边收进 0.10 mm，便于对准插入 |
| 整件最高处 | 1.20 mm，仅周边定位圈达到此高度 |
| 挡边搭接小孔 | 宽度方向每边 0.60 mm；长度方向每边 0.85 mm |

打印模型平放时，挡边在 Z=0..0.40 mm，定位圈在 Z=0.40..1.20 mm。安装后方向反过来：圈朝正面，挡边在内侧。挡边朝前的一面放在原壳 Z=-2.85 mm 台阶上；圈尖到壳体 Z=-3.65 mm，仍在原小孔内，未伸出正面。中央透光面占 Z=-2.85..-2.45 mm，不比 V2 更厚。

V1 的小平片没有承托，已被用户实物反馈否定。V2 的大平片虽有台阶承托，仍缺少插入孔中的定位结构。V3 用中空定位圈帮助安装，挡边限制沿正面方向穿孔掉出；不靠盲目增加过盈来宣称“卡紧”。**这不是双向卡扣：如果需要向内部翻转时也不脱离，应在挡边少量点胶固定。** 不假定 PCB 已提供压紧或限位。

## 打印和安装

白色 PLA、0.4 mm 喷嘴，100% 比例；0.20 mm 首层与层高，实心，平放，无支撑、无筏层。**大而平的挡边贴打印平台，定位圈朝上。** 中央膜片打印两层；只有周圈继续向上打印。耗材温度沿用正常配置。

安装时从外壳内部把定位圈朝正面小孔放入；先让圈对准孔，再将挡边平落到后方台阶。不要把大挡边穿过前孔，也不要把定位圈反朝 LED。透光面不贴压 LED。需要额外固定时，只在挡边少量点胶，避开透光区域。

本轮只做模型生成与文档交付，没有启动切片器、打印机、实物装配或透光效果测试。打印公差、圈的实际手感和光斑仍由用户体验反馈。

## 可调生成器

Python 标准库即可运行：

```sh
python3 hardware/interaction-led-diffusers-square4/v3-locating/generate.py
```

可调参数 `--membrane 0.40 --locator-height 0.80 --locator-gap 0.10`，均为毫米；gap 表示单边间隙。生成器不会修改外壳、启动切片器或发送打印任务。
