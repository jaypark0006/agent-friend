# square4 V2：0.40 mm 台阶承托均光薄片

2026-10-17，根据用户实物反馈“V1 太厚且会掉出”重新设计。适用于 `ESP-Mosaico_Module_Interaction_square4-3D.3mf`，不适用于 alignedcircles。

## 改正的结构依据

V1 只按 8.05 × 8.15 mm 的贯通孔减去间隙，得到 7.65 × 7.75 mm 平片。它没有任何机械承托面，会通过正面孔口掉出；0.80 mm 厚度也已被用户反馈为过厚。V1 不再推荐打印。

重新读取原壳网格在 Z=-2.851 与 -2.849 mm 两侧的截面，确认 **Z=-2.85 mm 有后方扩孔台阶**。中间两孔后方为约 9.55 × 10.15 mm、四角 R0.95 的凹位；两端凹位有向主腔连通的局部缺口，但对应的圆角矩形放置区域仍可利用。四片放置中心沿用原孔中心。

V2 是装在这个台阶上的大一圈薄片，利用四周超出小孔的部分作为挡边。从外壳内部放入，薄片朝正面的那一面落在台阶上。无需把薄片挤进前方小孔。

| 项目 | V2 尺寸 |
| --- | --- |
| 数量 | 四片相同，可互换 |
| 最大宽 × 长 × 厚 | **9.25 × 9.85 × 0.40 mm** |
| 四角半径 | R0.80 mm |
| 与后方矩形凹位的名义单边间隙 | 0.15 mm |
| 相对前方小孔的挡边搭接 | 宽度方向每边 0.60 mm；长度方向每边 0.85 mm |
| 底边小倒角 | 0.05 mm × 45°，底面挡边仍保留 |

0.40 mm 为整片透光厚度，没有在中央叠加第二层实体或厚框。正常摆放时占用壳体局部 Z=-2.85..-2.45 mm；原凹位隔板顶部约 Z=-2.09144 mm，仍有约 0.36 mm 余量。这不是实测 LED 间距。

**挡边解决的是向正面贯通孔掉出。** 此件没有倒扣，外壳未合拢时向内部翻转仍可能脱离台阶；如需要两个方向都固定，应在不透光的挡边处少量点胶/固定。没有以“增加摩擦”或“已经卡紧”冒充双向自锁。实物后方 PCB/LED 是否压住薄片尚未核验，不能把它当作已经确认的限位。

## 文件与打印

- `print-files/mosaico_square4_v2_ledge_040mm_4pcs.3mf`：四片独立物体，已平放排版，模型单位 mm。
- `print-files/01_square4_v2_ledge_diffuser.stl` 至 `04_square4_v2_ledge_diffuser.stl`：四份相同的 STL；也可只导入一份复制四次。
- `mosaico-square4-v2-ledge-040mm.zip`：本版完整包。

白色 PLA、0.4 mm 喷嘴，保持 **100% 比例**。采用 0.20 mm 首层和层高，整片两层，100% 实心、平放、无支撑、关闭筏层。温度使用耗材正常配置。不要让切片器沿用旧版 0.8 mm 的尺寸或做自动缩放。

**本轮没有启动切片器、打印机或设备做效果测试；新版装配与透光尚待用户体验反馈。** 原始壳体文件未修改。

## 参数

生成器只使用 Python 标准库：

```sh
python3 hardware/interaction-led-diffusers-square4/v2-ledge/generate.py
```

默认厚度 0.40、单边间隙 0.15、底边倒角 0.05，尺寸均为毫米。不得将此版生成器的间隙含义与 V1 混淆：V2 是相对**后方凹位**，V1 是相对**贯通小孔**。
